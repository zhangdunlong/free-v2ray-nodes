# free-v2ray-nodes

公开免费节点聚合（V2Ray / Sing-box / Clash 通用 URI）。节点来自公开订阅源，不保证可用性，仅供学习测试。

更新日期：2026-10-05

## 订阅链接

- 通用 Base64 订阅（v2rayN / v2rayNG / Shadowrocket 等）：
  https://raw.githubusercontent.com/zhangdunlong/free-v2ray-nodes/main/nodes_base64.txt
- 明文节点列表：
  https://raw.githubusercontent.com/zhangdunlong/free-v2ray-nodes/main/unique_nodes.txt
- 订阅源列表：
  https://raw.githubusercontent.com/zhangdunlong/free-v2ray-nodes/main/subscription.txt

## 文件说明

| 文件 | 内容 |
| --- | --- |
| subscription.txt | 订阅源 URL，每行一个 https 链接 |
| unique_nodes.txt | 去重后的明文节点 URI |
| nodes_base64.txt | unique_nodes.txt 全文的 UTF-8 Base64（单行） |

协议包含 vmess / vless / ss / trojan / hysteria2。免费节点变动快，导入后请自行测速。
